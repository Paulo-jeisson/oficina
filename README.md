🚗 Sistema de Gestão para Oficinas Mecânicas

Sistema SaaS desenvolvido com Django e Bootstrap.

Funcionalidades:
- Cadastro de clientes
- Cadastro de veículos
- Ordens de serviço
- Agendamento online
- Controle financeiro
- Assinaturas com Asaas
- Multiempresa

Tecnologias:
- Python
- Django
- Bootstrap
- SQLite/PostgreSQL
- AWS EC2
- Git

Como executar:

git clone ...
python -m venv venv
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
